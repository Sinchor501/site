Что такое HTML и CSS

Любой сайт собран из двух частей. HTML описывает содержимое: заголовок, абзац, ссылка. CSS описывает внешний вид: цвета, шрифты, отступы и расположение блоков.

Основы CSS

CSS-правило состоит из селектора и блока свойств в фигурных скобках. Селектор отвечает на вопрос «к кому применить», а свойства — «что изменить». 

p {
  color: blue;
  font-size: 18px;
}

Все абзацы <p> станут синими, а размер букв — 18 пикселей. Каждое свойство записывается как свойство: значение;.

Как подключить CSS

Три способа
СпособКак выглядитКогда использовать
Отдельный файл<link rel="stylesheet" href="style.css">Всегда, когда делаешь сайт
Тег style<style> p { color: red; } </style>Для небольшого опыта на одной странице
Атрибут style<p style="color: red;">Чтобы быстро изменить один элемент

Коробка элемента

Каждый элемент — прямоугольная коробка из трёх слоёв: рамка, внутренний отступ (padding) и внешний отступ (margin). Меняй ползунки и смотри на коробку и на код.

Содержимое
  • margin — внешний отступ
  • border — рамка
  • padding — внутренний отступ
